API reference / Referencia de la API¶

Generated automatically from the comments of the .m files in src/ldem (comments are written in Portuguese) / Generada automáticamente desde los comentarios de los .m.

Note

Only routines that already have a docstring (comment block right below the function line) are listed. To add another routine, document it and append it to this list / Para añadir otra rutina, documentarla y agregarla a esta lista.

Initialisation / Inicialización¶

ini_DEM3()¶

H1 this function put initial values in the global variables

read_dat0()¶

READ_DAT0 Lê os dados de entrada dos arquivos DATNAME(I).

prepvar()¶

PREPVAR Inicializa variáveis de tempo, energia e dimensões derivadas do modelo.

Geometry and connectivity / Geometría y conectividad¶

CONECTI()¶

CONECTI Define as conectividades de cada barra do reticulado.

INTCO1(MX, NX, LX, ST)¶

INTCO1 Define a conectividade das barras internas dos módulos cúbicos. Chamada por CONECTI.

Mechanics, loads and boundary conditions / Mecánica, cargas y contorno¶

RMEC()¶

RMEC Calcula as propriedades mecânicas das barras (exteriores, interiores e diagonais).

BOUND()¶

BOUND Determina as condições de contorno da estrutura. Deve ser adaptada para cada exemplo testado.

CALOAD()¶

CALOAD Aplica as cargas nos nós em cada passo de tempo. Calcula também a energia externa fornecida ao sistema.

Results and energy / Resultados y energía¶

CALRES()¶

CALRES Calcula valores que serão guardados no arquivo de resultados.

ENERG2(fid_EnB)¶

ENERG2 Avalia o balanço de energia a cada passo de integração. Grava as energias (externa, interna, cinética, elástica, dissipada) em fid_EnB.
