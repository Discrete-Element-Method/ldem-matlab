Autores
=======

Esta lista se genera automáticamente desde los commits del historial de git
(las personas con el mismo nombre o correo se unifican con ``.mailmap``) y
desde los autores de ``CITATION.cff``. Los autores sin commits en este
repositorio aparecen con ``-``. La misma lista está en ``AUTHORS.md``.

.. include:: ../_generated/authors.rst

Para actualizarla después de nuevos commits, construir la documentación o
ejecutar:

.. code-block:: bash

   python docs/tools/generate_authors.py

Si una persona aparece dos veces, agregar una línea a ``.mailmap``.
