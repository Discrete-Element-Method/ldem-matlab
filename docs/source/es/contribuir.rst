Contribuir
==========

La documentación de la API se genera desde los comentarios de los ``.m``. El
docstring debe ser el bloque de comentarios ubicado **inmediatamente después**
de la línea ``function`` (antes de cualquier ``global``). Los comentarios del
código se escriben en portugués.

.. code-block:: matlab

   function ini = CALOAD()
   % CALOAD  Resumen en una línea.
   % Descripción más larga.
   global ...

Ver ``CONTRIBUTING.md`` en la raíz del repositorio.
