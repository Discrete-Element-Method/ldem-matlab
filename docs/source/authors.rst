Authors
=======

This list is generated automatically from the commits of the git history
(people with the same name or e-mail are merged through ``.mailmap``) and
from the authors of ``CITATION.cff``. Authors without commits in this
repository appear with ``-``. The same list is in ``AUTHORS.md``.

.. include:: _generated/authors.rst

To update it after new commits, build the documentation or run:

.. code-block:: bash

   python docs/tools/generate_authors.py

If a person appears twice, add a line to ``.mailmap``.
