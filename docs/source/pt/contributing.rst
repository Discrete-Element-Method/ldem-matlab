Contribuir
==========

A documentação da API é gerada a partir dos comentários dos ``.m``. O
docstring deve ser o bloco de comentários colocado **imediatamente depois** da
linha ``function`` (antes de qualquer ``global``). Os comentários do código
são escritos em inglês.

.. code-block:: matlab

   function ini = CALOAD()
   % CALOAD  Resumo em uma linha.
   % Descrição mais longa.
   global ...

Veja ``CONTRIBUTING.md`` na raiz do repositório.
