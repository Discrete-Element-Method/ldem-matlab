Autores
=======

Esta lista é gerada automaticamente a partir dos commits do histórico do git
(pessoas com o mesmo nome ou e-mail são unificadas com ``.mailmap``) e dos
autores de ``CITATION.cff``. Autores sem commits neste repositório aparecem
com ``-``. A mesma lista está em ``AUTHORS.md``.

.. include:: ../_generated/authors.rst

Para atualizá-la depois de novos commits, construa a documentação ou execute:

.. code-block:: bash

   python docs/tools/generate_authors.py

Se uma pessoa aparecer duas vezes, adicione uma linha ao ``.mailmap``.
