Autori
======

Questo elenco è generato automaticamente dai commit della cronologia di git
(le persone con lo stesso nome o e-mail sono unificate tramite ``.mailmap``) e
dagli autori di ``CITATION.cff``. Gli autori senza commit in questo repository
compaiono con ``-``. Lo stesso elenco è in ``AUTHORS.md``.

.. include:: ../_generated/authors.rst

Per aggiornarlo dopo nuovi commit, costruire la documentazione oppure
eseguire:

.. code-block:: bash

   python docs/tools/generate_authors.py

Se una persona compare due volte, aggiungere una riga a ``.mailmap``.
