Contribuire
===========

La documentazione dell'API è generata dai commenti dei ``.m``. Il docstring
deve essere il blocco di commenti posto **subito dopo** la riga ``function``
(prima di qualsiasi ``global``). I commenti del codice sono scritti in
inglese.

.. code-block:: matlab

   function ini = CALOAD()
   % CALOAD  Riepilogo in una riga.
   % Descrizione più lunga.
   global ...

Vedi ``CONTRIBUTING.md`` nella radice del repository.
